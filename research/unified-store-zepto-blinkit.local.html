The layers, in one line each

  • Raw filesEvery download, byte for byte, never changed. The source of truth.
  • Loads and checksEach file is read and checked (headers, brand, totals) before anything is published.
  • Day-slicesOne per platform report × sheet × day. A re-download replaces a slice only when its numbers changed, and logs the change.
  • wh.fact_adThe unified detail rows: one shared column set for every platform.
  • mart.ad_dailyDaily totals per brand × platform × ad type. This is what the dashboards read.
